# Vendor_Performances
Vendor Sales Analysis project evaluating total sales, purchases, gross profit, profit margin, and unsold capital. Built using Python, SQL, Excel, and Power BI to perform data cleaning, EDA, KPI generation, and interactive dashboard creation for identifying top and low-performing vendors and brands.

# Data Set
The original dataset consisted of large transactional files (sales and purchases >500MB combined).
Due to GitHub storage constraints, representative sample datasets are provided.
The structure remains identical to the original data.
